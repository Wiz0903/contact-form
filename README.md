# Contact Form

A contact form built with HTML and CSS that demonstrates semantic HTML structure, form validation, accessibility basics, and custom styling.

## Features

* Full Name field (required)
* Email Address field (required)
* Phone Number field (optional)
* Message field (required)
* Contact reason selection using radio buttons
* Form validation using HTML attributes
* Submit and Reset buttons
* Custom CSS styling
* Responsive viewport setup

## Technologies Used

* HTML5
* CSS3

## What I Learned

Through this project, I practiced:

* Creating forms with HTML
* Using labels and form controls
* Grouping inputs with fieldsets and legends
* Implementing form validation
* Styling elements with CSS
* Working with margins, padding, colors, and buttons
* Organizing code into separate HTML and CSS files

## Project Structure

* `index.html` – Form structure and content
* `styles.css` – Styling and layout
